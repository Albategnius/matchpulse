# MATCHPULSE — project description

**Elevator pitch (≈60 words).** MATCHPULSE explains *why* a football match changed, not just what happened. It detects momentum swings, high presses, counterattacks, dominance and comebacks in synthetic event data, proves each one with before-and-after evidence, and turns the same verified insight into a fan story, an analyst breakdown and broadcast-ready graphics — with an AI reviewer that blocks invented numbers.

## Problem

Fans, analysts and broadcasters all see the same box score, but none of them get an explanation of the turning points that they can trust. Generic AI match reports read well yet invent statistics and claim tactical causes the data cannot support.

## Who it is for

- **Casual fans** — one line on the key moment and why it matters.
- **Analysts** — metric changes against a stated baseline, supporting events, confidence and limitations.
- **Broadcasters** — time-stamped narration and a JSON overlay payload for the graphics pipeline.

## What we built

- A Synthetic Match Lab with six reproducible scenarios and ground-truth labels.
- A deterministic analytics engine and explainable match-shift detector.
- A four-agent workflow on **Microsoft Agent Framework**: Event Analytics → Tactical Insight → Narrative & Personalization (Microsoft Foundry model) ⇄ Evidence & Quality Reviewer.
- A broadcast-style dashboard in English and Bahasa Indonesia, deployed on **Azure Container Apps**.
- An automated evaluation suite on held-out seeds.

## What makes it different (measured, not claimed)

1. **Evidence-to-story:** every sentence cites evidence ids; the reviewer verifies every number (100% of 1,292 template claims verified).
2. **Ground-truth-tested detection:** F1 0.84 on 180 held-out synthetic matches, with the weakest pattern (counterattack, F1 0.63) reported openly.
3. **Same insight, three real audiences:** different content and format, not a changed heading (word-overlap Jaccard 0.15–0.31 between modes).
4. **Hallucination guardrail you can watch:** a simulated faulty model invents numbers and causes; the reviewer rejects 215/215 corrupted claims, triggers regeneration, then approves.
5. **Correlation, not causation:** associative wording is enforced in code.

## Microsoft technologies

Microsoft Agent Framework (workflow orchestration), Microsoft Foundry (narrative model via `FoundryChatClient`, managed identity), Azure Container Apps (hosting), GitHub (source and reproducible evaluation).

## Synthetic data statement

All teams, players and events are fictional and generated by the project. No official Premier League data or intellectual property is used.
